# Paper Digests（基于 pdfminer 提取的全文）

格式：标题 → 核心方法 → 局限性 → 可突破点（对 AnyD4RT）

### World-R1（2604.24764，ICML'26）
- **方法**：在 Wan2.1 上做 Flow-GRPO-Fast。3D 奖励 R3D 由三项组成：meta-view 评分（VLM 评判重建后渲染的新视角）、渲染保真度（DA3 做 3D 重建，再用 3DGS 渲染）、轨迹对齐；另加通用生成奖励 Rgen。相机不单独编码，而是通过扭曲初始噪声注入（参照 Go-with-the-Flow）。训练数据是约 3000 条纯文本提示。
- **局限**：(1) 3D 奖励会让模型**过拟合到静态刚性**。为此每 100 步挂起 R3D，改在约 500 条动态提示上只用 Rgen 训练（"周期解耦"）。也就是说，动态区域得不到任何几何约束。(2) D.7 节承认：生成近乎静止的片段最容易重建，是一种奖励投机，只靠多项奖励组合加轨迹项来抑制。(3) 作者自述：RL 开销大；细粒度非刚性运动仍有伪影。
- **可突破点**：用 GT 动态轨迹给出位移奖励，**直接监督动态区域**，从而不再需要周期解耦（→ I5）。3D critic 是冻结的，没有被更新。

### CamVerse（2512.02870）
- **方法**：I2V 相机控制的在线 RL。对生成视频和参考视频分别估计相机轨迹，切成短片段，比较片段间的相对位姿，得到按片段的密集奖励。KL 系数 1e-4，参考模型取 SFT 之后的模型；前若干步用 SDE（噪声 0.7），其余用 ODE。另构建了 315k 视频的数据集。
- **局限**：奖励只衡量**相机**是否跟随，不约束场景几何和物体运动；需要参考视频，或者靠大规模估计出的轨迹标注；位姿估计器是冻结的。
- **可突破点**：借鉴"按片段给相对奖励"的思路，但对象换成点和轨迹（→ I5）；位姿估计器的误差会混进奖励，对应 README §3.5 盲区 3。

### VIGOR（2603.16271）
- **方法**：用 VGGT 计算跨帧、逐点的重投影误差作为奖励。几何感知采样会过滤低纹理和无语义区域。构建了 GB3DV-25k 偏好对，用于 SFT、DPO 式 RL 和测试时扩展（TTS，包括因果视频模型）。
- **局限**：只衡量生成视频**内部**的多视角一致性，没有外部 GT，所以"一致但错误"的几何不受惩罚；过滤掉低纹理区域，会漏检这些区域的失败；VGGT 以静态场景为主。
- **可突破点**：用外部 GT 轨迹给出绝对参照（G4）。

### GARDO（2512.24138）
- **方法**：只对约 10% 奖励不确定性最高的样本加 KL，不确定性用多个奖励函数之间的分歧衡量；参考模型定期更新为当前策略；对质量高且多样性高的样本放大奖励。
- **局限**：需要**多个独立的奖励模型**组成集成；在 T2I 上验证，没有测视频；奖励模型本身是冻结的。
- **可突破点**：在交替训练里，D₀、D₁……这些快照天然构成一个集成，不需要额外代价（→ I3）。

### DDRL（2512.04332）
- **方法**：用前向 KL 把策略锚定在一个离线数据分布上，等价于"相对奖励最大化加上在数据集上的扩散损失"。在视频上用了超过 100 万 H100 GPU 小时，做了 1 万次人工双盲评测。
- **发现**：DanceGRPO 和 Flow-GRPO 的奖励上升，但生成结果过度着色、过度风格化，是一种投机，本质是"用一项奖励换另一项奖励"；DDRL 能做到帕累托提升。
- **可突破点**：为 AnyD4RT 的 `λ_nat·L_denoise` 提供理论依据。锚定数据可以同时包括 Kubric-5D 和 9Mix 的真实源视频，在 C_b = C_a 时以源视频自身为目标（→ I3）。

### Prover-Verifier Games（2407.13692）
- **方法**：多轮迭代，同时训练小 verifier、helpful prover 和 sneaky prover（专门生成能骗过 verifier 的错误解）。verifier 的稳健性随轮次上升。
- **局限**：verifier 是**二分类器**，输出正确或错误；只在 GSM 上验证；存在"可读性税"，即准确率会下降。
- **可突破点**：对连续的几何回归 critic，"骗过"的含义要重新定义：critic 给出的奖励高，但 GT 投影误差大（→ I2）。

### Cooper（2508.05613）
- **方法**：policy 与 RM 联合优化。正样本由高精度规则验证器判定；负样本由辅助 LLM 把正确答案改错。RM 以参考答案为输入（reference-based）。
- **局限**：负样本改动后的"正确标签"不需要知道，因为 RM 只做二分类。
- **可突破点**：几何 critic 的负样本需要**已知标签的编辑**，也就是编辑后几何可以精确算出的视频（→ I1）。

### CURE（2506.03136）
- **方法**：coder 与 unit tester 协同进化。tester 的奖励 µ = p_u(1−p01) − (1−p_u)p00，由理论推导，衡量 tester 区分正确和错误解的精度。
- **可突破点**：critic 的训练目标可以直接写成"对同组候选排序的精度"，对应 S4 的 Kendall τ（并入 I1 的辅助项）。

### R-Zero（2508.05004）/ Absolute Zero（2505.03335）
- **方法**：Challenger 或提议者出的题落在 Solver 能力边界附近（成功率约 0.5），由此形成自适应课程；Absolute Zero 用代码执行器提供可验证的环境。
- **局限**：任务空间是离散的文本或代码；没有考虑"评判者自身可靠性"的约束。
- **可突破点**：连续的相机空间，加上 critic 可靠性约束，即共视覆盖率和 z-buffer 的已知区域（→ I4）。

### Meta-Rewarding（2407.19594）/ Self-Rewarding（2401.10020）
- **发现**：只改进生成器时，评判能力很快饱和。
- **可突破点**：为 H3 提供动机；S6 应当记录奖励随轮次的饱和曲线。
